# 가천 솔라맵

가천대학교 글로벌캠퍼스 19개 건물의 옥상 태양광 설치 타당성을 진단하는 웹페이지입니다.
(캡스톤디자인 최종발표 시연용)

**▶ 웹페이지 열기: https://202235875.github.io/gachon-solarmap/**

- 위성사진으로 옥상을 판독해 설치 가능 면적 산출
- 8,760시간 시뮬레이션으로 발전량 계산 (그림자 반영)
- 예산 안에서 발전량이 가장 많은 건물·배치 조합 추천
- 회귀분석으로 발전량을 좌우하는 요인 분석

지도: VWorld(국토교통부) · 건물 발자국: OpenStreetMap contributors, GIS건물통합정보
